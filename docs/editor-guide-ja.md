# World Gallery 編集者向け利用ガイド

最終更新: 2026-08-20

この資料は、Sanity Studioを使ってWorld Galleryの作品を追加・編集・公開する方のための手順書です。プログラムを変更する必要はありません。

## 1. 利用する画面

- 公開サイト: [https://world-gallery-studio.vercel.app/](https://world-gallery-studio.vercel.app/)
- 管理画面（Sanity Studio）: `クライアント配布時にURLを記入`
- SanityプロジェクトID: `kmx5m7v5`
- Dataset: `production`

管理画面URLは、一般公開サイトとは別です。編集者以外へ共有しないでください。

## 2. 初回ログイン

1. 管理者からSanityプロジェクトへの招待メールを受け取ります。
2. 招待されたメールアドレスでSanityアカウントを作成、またはログインします。
3. 管理画面URLを開きます。
4. プロジェクト名が `world-gallery-studio`、Project IDが `kmx5m7v5` であることを確認します。
5. 左側の一覧から `Work` を開きます。

ログインできない場合は、使用中のメールアドレスがSanityプロジェクトのメンバーとして招待されているか、管理者へ確認してください。APIトークンやPreview secretは編集者へ配布しません。

## 3. 作品を新規追加する

1. `Work` を開き、右上の新規作成ボタンを押します。
2. 次の「基本情報」を入力します。
3. `Content Blocks`で本文や画像を構成します。
4. 画面上部にエラー表示がないことを確認します。
5. 公開前に`Published`の状態を確認します。
6. `Publish`を押します。
7. 公開サイトの地球儀、Gallery、作品詳細を確認します。

### 基本情報

| 項目 | 必須 | 入力内容・注意点 |
|---|---:|---|
| Title (Japanese) | 必須 | 日本語の作品名。2〜120文字 |
| Title (English) | 任意 | 英語の作品名。未入力時は英語ページにも日本語を表示 |
| Subtitle (Japanese) | 任意 | 日本語の短い説明。200文字以内 |
| Subtitle (English) | 任意 | 英語の短い説明。未入力時は日本語を表示 |
| Slug (URL) | 必須 | URLの識別子。半角英小文字・数字・ハイフンを推奨 |
| Category | 必須 | 5種類から1つ選択 |
| Published | 必須 | ONで一般公開、OFFで一般公開から非表示 |
| Location | 必須 | 緯度・経度と日英の地名 |
| Cover Image | 必須 | 地球儀カード、Gallery、作品詳細、SNS共有に使用 |
| Content Blocks | 必須 | 本文、画像、グリッドなどを1件以上追加 |
| Date | 任意 | 作品の日付。Galleryなどの新着順に使用 |
| Tags | 任意 | 管理用キーワード。最大20件 |

### Slugのルール

- 例: `tokyo-observation-sketch`
- 半角英小文字、数字、ハイフンだけを推奨します。
- `Generate`で期待どおりにならない場合は手入力してください。
- 一度公開したSlugを変更すると、以前のURLや共有済みリンクが使えなくなります。公開後は原則変更しません。
- 他作品と同じSlugは使用しません。

### Category

- `Sketch` — スケッチ
- `Architecture` — 建築
- `Travel` — 旅
- `Research` — リサーチ
- `Other` — その他

Categoryは地球儀のピン色とGalleryの絞り込みに使われます。

### Location

- Latitude（緯度）: 北緯はプラス、南緯はマイナス。入力範囲は`-90〜90`
- Longitude（経度）: 東経はプラス、西経はマイナス。入力範囲は`-180〜180`
- Place Name (Japanese): 例 `東京都、日本`
- Place Name (English): 例 `Tokyo, Japan`

緯度・経度を逆に入力すると、地球儀の別の場所にピンが表示されます。公開後は必ず地球儀で確認してください。

## 4. Content Blocksで作品ページを作る

`Content Blocks`では、追加した項目をドラッグして自由に並べ替えられます。

### Text

- `Body (Japanese)`へ日本語本文を入力します。
- `Body (English)`へ英語本文を入力します。
- どちらか一方は必須です。
- 英語が未入力の場合、英語ページには日本語本文が表示されます。

### Image

- 画像を1枚表示します。
- `Alt`には、画像が見えない方にも内容が分かる短い説明を入力します。
- `Caption (Japanese)`と`Caption (English)`を必要に応じて入力します。
- `Width`は`Full`、`Medium`、`Narrow`から選択します。

### Image Grid

- 2枚以上の画像を並べて表示します。
- `Columns`で1〜4列を選びます。スマートフォンでは画面幅に合わせて自動調整されます。
- `Gap`で画像間隔を選びます。
- 各画像にAltと日英Captionを設定できます。

### Spacer

- セクション間の余白です。
- `S`、`M`、`L`から選択します。

### Divider

- セクションの区切り線です。
- `Solid`または`Dashed`を選択します。

### 使用しない旧項目

次の項目は既存データとの互換用です。新しい作品では原則使用しません。

- `Hero Image (Legacy)`
- `Gallery Images (Legacy)`
- `Text (Legacy)`
- `Title (Legacy)`
- `Created At (Legacy)`

画像や文章は`Cover Image`と`Content Blocks`へ入力してください。

## 5. 画像を追加する際の注意

- Cover Imageは、トリミングされても主題が分かる画像を選びます。
- 可能であれば横幅1600px以上の高画質画像を推奨します。
- JPEG、PNG、WebP、AVIFなど一般的な画像形式を使用します。
- 同じ画像を何度もアップロードせず、既存アセットを再利用します。
- ファイル名だけではなく、各画像の`Alt`も入力します。
- 人物、個人情報、第三者の作品が写る場合は、公開権限を事前に確認します。

## 6. 保存・公開・非公開の違い

Sanityには、次の2つの状態があります。

1. Sanityの下書き／Publish
2. 作品項目内の`Published` ON／OFF

### 新規作品を安全に準備する

1. 作品を新規作成します。
2. 一般公開したくない場合は、最初に`Published`をOFFへ変更します。
3. 内容を入力して`Publish`します。
4. `Published`がOFFなので、公開サイトには表示されません。
5. 確認完了後、`Published`をONへ変更して再度`Publish`します。

### 公開中の作品を編集する

- 編集中の変更は、`Publish`するまで公開サイトへ反映されません。
- `Publish`後、公開サイトへの反映に少し時間がかかる場合があります。
- 更新後は必ず日本語・英語の両ページを確認します。

### 一般公開から取り下げる

1. 対象作品を開きます。
2. `Published`をOFFにします。
3. `Publish`します。
4. 地球儀、Gallery、作品URLから見えなくなったことを確認します。

`Published`をOFFにしてもデータは削除されません。作品そのものの削除は復旧が難しくなるため、管理者確認なしに行わないでください。

## 7. Preview

非公開作品は、通常の公開URLを直接開いても表示されません。Preview Modeを使うと、許可された管理者だけが確認できます。

現時点では、Sanity Studio内のPreviewボタン連携を設定中です。連携完了までは、管理者から発行された安全なPreviewリンクを使用してください。

- Previewリンクには秘密情報が含まれるため、メール転送、チャット転載、スクリーンショット掲載を避けます。
- Preview中は画面上部にPreview表示が出ます。
- 確認後は`Exit preview`を押します。
- Preview secretやAPIトークンを編集者自身で設定する必要はありません。

## 9. よくある問題

### Publishできない

画面上部または入力欄付近の赤いエラーを確認します。主な原因は次のとおりです。

- 日本語タイトルが未入力
- Slugが未生成
- Categoryが未選択
- Publishedが未設定
- Locationまたは緯度・経度が未入力
- Cover Imageが未設定
- Content Blocksが空

### 公開サイトに表示されない

- Sanity上で`Publish`したか確認します。
- `Published`がONか確認します。
- Slug、Category、Location、Cover Imageの必須エラーがないか確認します。
- 数十秒待ってページを再読み込みします。
- それでも表示されない場合は、作品名とSlugを管理者へ伝えます。

### 地球儀の場所が違う

- LatitudeとLongitudeが逆になっていないか確認します。
- マイナス記号の有無を確認します。
- 修正後に再度`Publish`します。

### 英語ページに日本語が表示される

仕様どおりです。英語欄が未入力の場合、日本語をフォールバック表示して検索対象にします。英訳を入力して`Publish`すると英語表示へ切り替わります。

### 画像の見え方がよくない

画像欄のCrop／Hotspotで主題位置を調整します。Cover Imageは複数の縦横比で利用されるため、端に重要な要素を置きすぎないようにします。

## 10. 権限とセキュリティ

- 編集者は自分のSanityアカウントを使用し、アカウントを共有しません。
- APIトークン、Preview secret、環境変数は共有・入力しません。
- 不審なログイン通知があった場合は管理者へ連絡します。
- メンバー追加・権限変更・データセット操作は管理者が行います。
- 作品削除、複数作品の一括変更、画像アセット削除は管理者確認後に行います。
